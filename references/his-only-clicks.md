# His-only clicks

*Version 0.1.0 (2026-11-24).* Read before telling Charles a step is his: creating, sharing or saving a key, token or permission, or any setting only he can change (charter 5: "one clear card, the exact click"). Getting to the pages follows `references/browser-use.md`; read it first.

("When there is tech work that Claude can't do like secrets etc, I want it to open all the locations in GitHub, Google, Vercel etc that need to be opened." Charles, 2026-11-24.)

## Steps

1. First check whether the step needs no click of his at all: keys passed machine to machine (`skills/wire-new-app`), or a connector that already has the access. Only what's left comes here.
2. Work out the full list of pages before opening any: every place the key, token or permission is created, shared and saved (GitHub, Google, Vercel, Supabase and so on).
3. Open them all, one tab each, in the order he'll use them, on the PC he's at.
4. Give him one card: a numbered list, one line per tab, the exact click and the exact name to type or pick. Say where each value goes next ("copy it; tab 3 is where it's pasted"). Never ask him to paste a value into the chat.
5. Stop looking: once a page may show a secret value, take no screenshot and read no page text until he says he's done.
6. When he says done, check the result by name only (the secret's name exists, the permission shows, the run goes green), never by value. Then close the tabs.

## Proven

2026-11-23, the personal Gmail setup, in Chrome with Charles at the PC.

## Keeping this file right

A page that moved, a step that was missing, a site with a new flow: the chat that hit it fixes the line here in the same turn, dated, without asking.
